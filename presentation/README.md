# Presentation

Open `index.html` in a browser. No server is needed.

- Keyboard shortcuts are enabled. No navigation controls are shown on screen.
- Sliders and the policy toggle on slides 7 to 11 are interactive.
- Results on slide 14 are static.
- Add `?theme=dark` or `?theme=light` after the hash to force a theme for a
  screenshot, for example `index.html#slide-1?theme=dark`.

The deck uses only local assets.
