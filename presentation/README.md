# Presentation

Open `index.html` in a browser. No server is needed.

- Arrow keys, Page Up, Page Down, and Space move between the 15 slides.
- `T` switches between the light and dark theme. The choice is remembered.
- Sliders and policy buttons on slides 7 to 11 are interactive.
- On slides 13 and 14, use the metric and rate controls to redraw the charts.
- Add `?theme=dark` or `?theme=light` after the hash to force a theme for a
  screenshot, for example `index.html#slide-1?theme=dark`.

The deck uses only local assets.
